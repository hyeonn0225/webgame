# LAST SIGNAL — 온라인 2인 배틀로얄

Vercel + Supabase Realtime 기반 탑다운 PvP 게임입니다. 각자 컴퓨터에서 같은 주소를 열고 방 코드로 참가합니다.

## 플레이

1. 방장이 전장을 만들고 6자리 코드를 공유합니다.
2. 두 명 접속 후 방장이 시작합니다.
3. 지도에서 각자 착지 지점을 클릭합니다. 20초 동안 미선택 시 자동 배치하고 3초 강하 후 전투를 시작합니다.
4. 무기와 탄약을 각각 주워 장전합니다. 마우스로 직접 조준하고 사격합니다.
5. 건물이나 부쉬에 들어가면 해당 공간 내부가 드러납니다. 밖에서는 내부의 적과 전리품이 보이지 않습니다.
6. 자기장 안으로 이동하며 최후의 1인이 되면 승리합니다. 동시에 사망하면 무승부입니다.

| 조작 | 동작 |
|---|---|
| WASD / 방향키 | 이동 |
| 마우스 / 좌클릭 | 조준 / 사격 (누르고 있으면 무기 발사 주기에 따라 연속 발사) |
| F | 가장 가까운 아이템 줍기, 총기가 있으면 교체 |
| R | 현재 무기 장전 |
| Q | 회복제 사용 (2.5초, 체력 +60) |
| M | 전술 지도 |
| P | 공동 일시정지 / 재개 |

총기는 P92, VECTOR, M416입니다. 권총과 SMG는 9mm, 소총은 5.56mm 탄약을 사용합니다. 새 총기는 빈 탄창으로 획득하며 탄약을 확보한 뒤 R로 장전해야 합니다. 건물 출입구는 아래쪽 중앙입니다. 벽은 이동과 총알을 막습니다.

## 실행 및 배포

[DEPLOY.md](DEPLOY.md)에 Vercel 환경 변수와 배포 절차를 정리했습니다. 기존 SUPABASE_URL과 SUPABASE_PUBLISHABLE_KEY를 그대로 사용합니다.

로컬: Node.js 20 이상에서 `npm run build` 후 `npm start`. Windows 실행 정책 오류 시 `npm.cmd`를 사용합니다.

- `npm test`: 착지, 파밍, 탄약, 은폐, 벽 충돌, PvP, 자기장, 입장 권한 테스트.
- `node browser-test.cjs`: Playwright와 Chrome으로 두 페이지를 실행합니다. PLAYWRIGHT_PATH에 Playwright 모듈 경로를 지정하거나 임시 폴더 webgame-browser-check에 설치합니다. Supabase를 로컬 BroadcastChannel로 대체하는 통합 테스트이며 실제 서비스 연결 시험은 아닙니다.

## 구현 범위

2400×2400 전장, 건물 16채, 부쉬, 3종 총기, 탄약, 회복제, 5단계 자기장입니다. 이전 협동 생존 및 무한 맵 설계를 대체합니다. 두 플레이어가 각자 착지하기 때문에 비행기 경로 조종은 없습니다.

방장 브라우저가 게임을 계산하며 Supabase는 메시지를 중계합니다. 일반 참가자에게 전달하는 상태에서 은폐된 상대의 좌표·장비와 내부 전리품을 제외합니다. 방장 자체는 전체 상태를 소유하므로 치트 방지 서버는 아닙니다. 공개 Broadcast 채널의 친구용 프로토타입입니다.

참가자 화면은 90ms 분량의 수신 상태를 보관하고 플레이어·탄환 위치를 화면 갱신 주기에 맞춰 보간합니다. 초당 15회 수신한 좌표를 그대로 그릴 때 발생하는 끊김을 줄입니다. 네트워크 왕복 지연 자체를 제거하는 기능은 아니며, 실제 인터넷 환경의 체감은 배포 후 확인해야 합니다.

방장 탭을 열어두세요. 탭이 숨겨지거나 연결이 잠시 끊기면 일시정지합니다. 새로고침·탭 종료 후 진행 복구와 방장 이전은 지원하지 않습니다.
